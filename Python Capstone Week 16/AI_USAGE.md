I gave AI my idea for the project and had it help me break down how to build it in different sections. It suggested I start with input validation, then input handling, then processing of data, and lastly the output creation. This helped me a ton to break down the construction process and build it step by step. I also had it create the input data for me as I wanted a variety of data to be created quickly. I only used ChatGPT as my AI source as that is my main stream of all AI usage.

The first prompt I entered into ChatGPT was with my idea of the project and prompted “help me break down the construction process of this python tool so I can build it step by step, make any suggestions you think are necessary for changes.” The second prompt I used was “create test data for this budget analyzer tool each with their own date, category, amount, and description, with all transactions coming from an IT department, make around 50 transactions. Another prompt I used after week 14 was “how could I improve this python tool to make it more effective and add more error handling.” I took all of the suggestions from AI as they were super helpful and sped up the building process and effectiveness of my tool a ton.

The test data that AI gave me did not include any categories that had overspending. I modified one of the categories to have overspending to ensure that the overspending analyzer feature worked properly which it did. AI also suggested names for each feature that I wanted to add but I did not take the suggestions as I had already had my own plan for their names that were much more clear and simple. 

After completion of building my python tool, I used pytest to ensure that my AI modified tool was working properly. The terminal output showed 4 out of 4 successful features which let me know my tool was completely working properly. 

Responsible AI usage is using AI to assist you and not to let it do the whole thing for you. You can easily abuse AI with it doing a task completely for you which does not really teach you anything. You should still know how to do a task without any usage of AI but using AI is effective and speeds up the process of your tasks.
